A README tells you what a project does. It rarely tells you which small annoyance made it worth building in the first place.

That’s what I want to write down here. Sometimes it’s the reason I started an Obsidian plugin. Sometimes it’s a decision I made while running a Minecraft server. The projects have their own pages. These are the notes I’d want to find six months later.
